# Members Only

The Odin Project - NodeJS Course Project (3/8):

An anonymous message board where anyone can view messages, but only registered users can see who authored each one.

This application uses Express, PostgreSQL, Passport.js, EJS, and bcyrptjs, and is deployed via Render and Supabase.

## Features

- User authentication: login system based on express-sessions and Passport.js
- Create and view messages
- Secret passcode system to unlock member chatroom
